# 0.9.0

ISO week dates (`2026-W07-3`) parse, and the error type is now one
`ParseError` carrying the offset it gave up at rather than four exception
classes callers had to catch separately.

- **Added** — ISO week dates, `ParseError.offset`
- **Changed** — the four parser exceptions collapse into `ParseError`;
  the old names remain as aliases and warn until 1.1
- **Removed** — `parse_loose()`, deprecated since 0.6
- **Fixed** — two-digit years no longer clamp to 1999
