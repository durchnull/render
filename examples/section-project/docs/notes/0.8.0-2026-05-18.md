# 0.8.0

Relative phrases (`next friday`, `in 3 weeks`, `end of month`) resolve
against an injectable `now`, so callers can test them without freezing the
clock globally. `parse()` gained `tz`; naive input stays naive.

- **Added** — relative phrase grammar, `tz` argument, `Span` return type
- **Changed** — `parse()` returns `Span` for ranges instead of raising
- **Fixed** — `31.02.` no longer rolls into March
